# Function to pre-process data for vignettes

Function to pre-process data for vignettes

## Usage

``` r
pre_process_coding_alone(out_dir = NULL, f_name = "pre-processed")
```

## Arguments

- out_dir:

  Directory containing all raw data

- f_name:

  Name of file in which pre-processed data are to be saved (in
  `out_dir`).

## Value

Full path to saved file containing all pre-processed data.
